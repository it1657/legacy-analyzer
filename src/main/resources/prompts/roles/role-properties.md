### Properties (.properties) → `#` 주석
- 각 설정 키 바로 위 줄에 `#` 주석으로 그 설정이 담당하는 업무·인프라 목적을 설명
- 하드코딩된 호스트·포트·계정·경로·타임아웃 값은 실제 운영 환경에서 무엇을 가리키는지, 왜 그 값인지 설명
- `spring.profiles.active`, `-postgres`/`-h2` 같은 프로필별 파일 분리가 있다면 어떤 조건에서 해당 프로필이 활성화되는지 설명
- 인라인(줄 끝) 주석은 지양하고, 설정 키 바로 위 줄에 별도 `#` 주석으로 작성
```properties
# {실제 설정 키가 담당하는 업무·인프라 역할을 코드/값에서 확인하여 설명}
{실제 설정 키}={실제 설정 값}
```
