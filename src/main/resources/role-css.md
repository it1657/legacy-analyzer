### CSS (.css) → `/* ... */` 블록 주석
- 각 규칙(selector) 또는 규칙 그룹 바로 위 줄에 `/* ... */` 주석으로 그 화면 요소가 담당하는 역할을 설명
- `//` 한 줄 주석은 절대 사용하지 않는다 — 표준 CSS 문법이 아니며 파서에 따라 무시되거나 스타일이 깨진다
- 하드코딩된 색상 코드·크기·z-index 값은 실제로 어떤 화면 요소/레이아웃 문제를 해결하기 위한 값인지 설명
- `!important`, 매직 넘버성 크기 값(예: `1650px`)이 있으면 어떤 문제를 우회하기 위한 것인지 설명
```css
/* {실제 규칙이 담당하는 화면 요소·레이아웃 역할을 코드에서 확인하여 설명} */
{실제 선택자} { {실제 속성}: {실제 값}; }
```
