### YAML (.yml, .yaml) → `#` 주석
- 각 키(서비스/스텝/설정 항목) 바로 위 줄에 `#` 주석으로 그것이 담당하는 업무·인프라 역할을 설명
- 하드코딩된 이미지 태그·포트·환경변수·계정 값은 실제 운영 환경에서 무엇을 가리키는지 설명
- `depends_on`, `profiles`, `condition` 등 서비스 간 의존·조건부 실행이 있으면 그 의존 관계가 존재하는 이유를 설명
- 들여쓰기(계층 구조)는 절대 변경하지 말 것 — YAML은 들여쓰기 자체가 문법이므로, 주석 삽입으로 계층이 흐트러지면 파일이 깨진다
```yaml
# {실제 키/서비스가 담당하는 업무·인프라 역할을 코드/값에서 확인하여 설명}
{실제 키}: {실제 값}
```
