## 1. 지금 시스템은 어떻게 동작하나 (핵심 사실)

| 항목 | 현재 사실 |
|---|---|
| Provider 선택 | **런타임 리졸버**(`LlmClientResolver`)가 DB `llm_model_options`의 `provider` 값으로 매 호출마다 구현체를 고른다. `llm.provider`는 **DB에 없는 모델명에 대한 폴백 기본값**으로만 남아 있다 |
| 모델 목록 | DB + 관리자 CRUD(ADMIN 전용). 사용자 조회는 `GET /api/config/llm-models`, 설치 여부는 `/local-installed`(TTL 캐시, `available=false`는 "설치 없음"이 아니라 **"확인 불가"**) |
| 접근 권한 | **Anthropic = 허가제**(API 키 + `ANTHROPIC_USER` Role, admin은 항상 통과) / **로컬 = 기본 개방** |
| 비상용(임시) 모델 목록 | 하드코딩 임시 목록이 표시된 상태에서는 **분석이 시작되지 않는다**(59차). 두 진입점 모두 안내 alert 1회만 띄우고 `/api/start-analysis`를 호출하지 않는다 |
| 원본 소실 | `SessionSourceAvailability`가 재개 전에 판정한다. **전량 소실이면 `SOURCE_MISSING`으로 거부**(상태·대기 목록 불변), **일부 소실이면 남은 파일만 재개**하고 소실분은 실패로 기록한다. **기록은 삭제하지 않는다** |
| **재개 카운터 — 60차 신규** | 재개 시작 때 처리 수를 **`총계 − 대기 수 + 소실 수`로 다시 세고 실패 수는 0에서 다시 센다.** 총계 상한 클램프는 **두지 않는다** — 저장값이 총계를 넘었으면 **경고 로그만** 남기고 재기준값으로 교체한다. **원본이 사라진 파일도 "끝난 파일(실패)"로 센다.** 로그 `[재개 카운터 재기준]`·`[재개 카운터 재기준 생략]`·`[카운터 불변식 위반 감지]` |
| **재개 이월 실패 — 60차 신규** | **이전 재개에서 소실이 확정된 실패는 재기준 뒤에도 실패로 유지**된다(`[재개 이월 실패]`). 이 블록이 없으면 **일부 소실 세션을 두 번 재개할 때 실패 수가 처리 수보다 적어진다** |
| **이력 카운터 — 60차 신규** | **재개 경로의 일시정지·전량실패 분기에서도** 이력에 카운터를 기록한다. 이력과 세션이 어긋나지 않는다 |
| **오류 분류 — 60차 신규** | `ApiErrorHandler.classifyError()`가 **메시지 검사보다 상태 코드를 먼저** 본다. `RetryHandler`는 **같은 분류기에 위임**한다. **401은 `API_AUTHENTICATION`이고 재시도하지 않는다**(종전에는 `CONNECT_FAILURE`로 오분류돼 파일당 12회 시도) |
| **실패 사유 집계 — 60차 신규** | 집계 키가 **메시지 전문이 아니라 `errorType`**이고, 표시용 **이름표가 분리**돼 있다(`인증 실패(API 키 확인 필요)` 등 9종). 전량실패 안내에 **타임스탬프를 넣지 않는다**. 그래서 같은 원인이 `request_id` 때문에 N종으로 쪼개지지 않는다 |
| 종단 세션 보호 | 끝난 분석에 대한 일시정지는 `SESSION_TERMINAL`로 거부되고 상태를 바꾸지 않는다(59차) |
| failover | 크레딧 소진 시 관리자 지정 모델로 이어갈지 사용자 컨펌 — `AWAITING_FAILOVER_CONFIRM`(종료 상태 아님) |
| RAG | A안(패키지 구조 압축) + B안(코드 내용 청킹) 독립 토글 2개 |
| 토큰 집계 | **세션 키 맵으로 격리**(56차). 재개 경로는 리셋하지 않는다(일시정지 구간 토큰이 영구 소실되기 때문). 키가 같으면(동일 경로 동시 분석) 여전히 합산된다(§4-B 이월) |
| 비용 계산 | **세션이 실제로 라우팅되는 provider로 판정**(56차). `resolveEffectiveProvider()` 하나로 모으고 계약 테스트로 고정 |
| 모델 단가 | `AnthropicModelPricing`이 **정확 키 → `claude-` 패밀리 → 미지 모델은 최고 단가 + WARN** 순으로 결정(56차). **단가 문자열의 정본은 이 한 곳뿐**이고 API가 `pricing` 필드로 내린다(58차) |
