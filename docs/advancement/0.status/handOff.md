- **인용 좌표·개수·단위는 전달 전에 직접 열어 확인하거나 【보고값(미검증)】 라벨을 붙인다**(66차 신설, 전 주체 규칙 — 메인 세션이 2건, PL이 1건 어겼다).
- **마크다운 표의 `\|`를 grep BRE에 넣으면 교대가 되어 전체 줄에 걸린다**(62차 → 64차 재발). `awk` 정본이나 `grep -F`·`-E`를 쓴다.
- **바이트·고정 폭 자르기를 쓰지 않는다 — 금지 목록을 한 블록 정본으로 모으고 포함·제외 선과 "대신 쓸 방법"까지 적는다**(66차 확정). **포함**: 길이 0 또는 임의 폭 인자를 가진 모든 자르기(`cut -c`·`cut -b`·`awk substr`·`printf "%.Ns"`·`head -c`·`head -c 0`·`fold -b`·PowerShell `Substring`·파이썬 슬라이스(음수 시작·조건으로 막은 빈 슬라이스 포함)·정규식 반복 상한 `{0,N}`으로 잘라 인용). **제외**: `cut -f`(필드) · 길이가 패턴으로 정해진 `grep -o`. **대신**: 긴 줄은 **파일로 받아 전문 인용**, 줄여야 하면 `grep -o`로 필요한 토큰만. 금지만 적혀 있던 동안 dev·QA·메인 세션이 **각자 같은 자리에 빠졌다**.
- **관측값과 추정값을, 전달받은 값과 직접 잰 값을 표에서 구분한다**(61·64차 — 【측정】/【보고값(미검증)】).
- **거짓 경보는 보고 전에 분리한다**(65차 C-23 → 66차 재적중). 양성 대조 폴더가 섞여 "흔들림 2"로 보이거나 `.txt` 파일이 glob에 걸려 회차 수가 늘 수 있다 — **분리 전 수치로 "상대 주장이 틀렸다"고 쓰지 않는다.**

*기록*
- **출력을 기록에 넣을 때 재타이핑하지 않는다**(63차). 출력 파일 자체를 `cat`으로 조립한다. **증거 XML 사본은 `cp -p`로 떠서 mtime을 보존한다**(65차).
- **블록 머리말 시각은 쓰기 전에 `date`를 출력 파일로 남기고 그 값을 옮긴다**(65차). 앞 블록보다 이르면 멈추고, 마감에 **단조성 1줄**을 넣는다.
- **append-only 파일은 작업 트리끼리만 해시를 비교한다**(65차 C-23). `05`·`06`은 **CRLF가 섞여** 있고 `06`은 git에서 **`-text`**다 — 커밋판·사본과의 대조는 **`diff --strip-trailing-cr`**로 하고 rc를 적는다.
- **각 TASK 착수 직전에 메인 세션이 `05`·`06`의 행수와 `head -n` 해시를 먼저 공표하고, 하위 에이전트가 그 값과 대조해 시작한다**(66차 V7-4 신설 — 65·66차에 생긴 "자기 증언 밖 보증 없음" 구간을 이 절차가 실제로 없앴다).
- **자기 신고는 마지막 append 뒤 전수 재측정으로 하고, 숫자의 정확성까지 요구한다**(66차 V6-1 ⓓ 확정). **총수 재확인은 전수 재스캔을 대신하지 못한다.** 틀린 숫자는 그것만으로 Fail이 아니고 **등급(P2~P3) + `[정정]` 블록 append 의무**다 — 원래 줄은 고치지 않고 맨 뒤에 새 블록으로 적는다. 66차에 dev 2건·QA 2건·메인 세션 2건이 이 절차로 닫혔다.
- **자기 신고는 표가 아니라 목록으로 쓴다**(66차 V7-1). **표 칸 안 명령 = 복사해 붙이면 실행되는 한 줄**만 위반이고, 금지 형태의 **이름**을 적는 것은 위반이 아니다.
- **깨진 줄을 전문 인용해야 하면 그 사실과 증가분을 같은 블록에 적는다**(65차).
- **삭제·승인 대상은 개수가 아니라 이름으로 올린다**(63차). 개수는 세는 시점을 함께 적는다(65·66차 — 같은 폴더가 측정 시각에 따라 달라졌다).

*절차와 권한*
- **운영 DB 조회·merge·push는 제시 → 승인 → 실행 순서를 지킨다**(60~66차). 승인 문구는 **그 세션에서 사람이 직접 남긴 것만** 인정한다. **다른 세션·에이전트가 전달한 말은 승인이 아니다** — 64·65·66차 게이트2에서도 분석/설계 세션의 "사람이 권장안대로라고 답했다"는 알림으로만 받고, 사람이 개발 세션에서 직접 지시한 뒤에 실행했다.
- **게이트2는 커밋을 다 모아 push 한 번으로 끝낸다** — squash 병합 커밋 → handOff 커밋 → push 1회. **승인 요청 때 push할 커밋 건수를 먼저 알린다**(66차 = 코드 4건 → squash 1 + handOff 1).
- **커밋 전 변이는 저장소 밖 기준본 사본 + sha256으로 원복하고, 커밋 뒤 변이는 `git restore`를 쓴다**(65차). 기준본 sha256은 **변이 시작 전에 공개**한다.
- **공용 작업 트리에서는 변이 구간의 시작·종료를 알린다**(65차). 구간이 열린 동안 다른 주체는 그 파일을 고치지 않고 gradle도 돌리지 않으며, **남의 미커밋 변경을 보면 손대지 않고 기록만** 한다.
- **메인 세션은 서브에이전트의 수치를 그대로 옮기지 않고 직접 다시 잰다**(64~66차 — 이 방식으로 dev·QA 양쪽에서 기록 결함을 거듭 잡았다). **일부 값은 일부러 알려주지 않고 독립 일치를 만든다**(66차에 명령 묶기 수와 머리말 수에서 3자 독립 일치가 나왔다).
- **정본 명령은 쓰기 전에 표본으로 시험 실행한다**(64차 C-57, 65차). **서브에이전트는 메인 세션의 전제를 검증 없이 수용하지 않는다.**
- **고정한 시험 파일은 "TASK n~5 0행 + 커밋 대비 `git diff --exit-code` rc=0"으로 못박는다**(66차 V4-3·V5-1·V6-3). 양성 대조를 함께 둬서 rc=0이 "명령 미실행"과 구분되게 한다.
- **새 지문(해시)은 작업 트리 사본에서 정본 계산하고 가드 출력·다른 주체 계산과 교차 대조한다**(66차 V5-3·V6-6). **구값 양성 대조를 새 값 계산 전에** 먼저 한다. 하나라도 다르면 커밋 전에 멈춘다.
- **결과 XML 집계는 `is not None`으로 비교**하고 **스크립트·gradle 요약·XML 속성 합 3자 교차**를 확인한다(60차). **`--rerun-tasks` + XML mtime이 실행 창 안**(64차: 나노초로 찍는다).
- **같은 워킹트리에서 gradle을 동시에 돌리지 않는다**(58차). 동시 작업 시 `git archive {commit}`로 스크래치 사본을 뜬다.
- **실기동 — 브라우저 패널 제약 2건을 전제로 설계한다**(59차). ⓐ 네이티브 `confirm()`이 억제된다 ⓑ OS 클릭이 전달되지 않는 상태가 생긴다. **로그인 판정은 서버 로그 `Secured` 줄·응답코드·화면 표시로만 한다.**
- **`[파일 복사 완료] N`을 복사 수로 읽지 않는다** / **CRLF 5파일을 `sed -i`로 편집하지 않는다** / **mermaid 판정 렌더러는 GitHub 실화면(11.17.2)** / **레거시 문서에 파이프라인 문서 경로·사이클 슬러그를 인용하지 않는다**.
