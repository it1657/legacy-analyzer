*측정과 증거*

- **변이는 "지우기"보다 "옮기기"가 시험 범위를 잰다**(65차 신설). 검사를 부작용 호출 뒤로 옮기거나 해제를 다른 분기로 옮기면, 지우기로는 안 드러나는 공백이 드러난다 — 65차에서 위치 요건 2건이 보호됨을 확인하고 해제 범위 공백 1건을 찾았다.
- **합계가 맞는다는 것은 내역이 맞다는 증거가 아니다**(60차). **적은 개수마다 가수를 다시 더해 확인한다**(65차에 합계 오기 1건·좌표 오기 2건이 그래서 났다).

- **마크다운 표의 `\|`를 grep BRE에 넣으면 교대가 되어 전체 줄에 걸린다**(62차 → 64차 재발). 파이프를 리터럴로 셀 때는 `awk` 정본이나 `grep -F`·`-E`를 쓴다.

*기록*
- **출력을 기록에 넣을 때 재타이핑하지 않는다**(63차). 출력 파일 자체를 `cat`으로 조립한다. **증거 XML 사본은 `cp -p`로 떠서 mtime을 보존한다**(65차 — 그냥 `cp`면 사본에서 재면 복사 시각이 나온다).
- **블록 머리말 시각은 쓰기 전에 `date`를 출력 파일로 남기고 그 값을 옮긴다**(65차 신설). 머리말 시각이 앞 블록보다 이르면 멈추고 확인하고, 마감에 **단조성 1줄**을 넣는다 — 65차에 미리 쓴 시각이 세 번 틀렸다.
- **append-only 파일은 작업 트리끼리만 해시를 비교한다**(65차 C-23). `05`·`06`은 **CRLF가 섞여** 있고 `06`은 git에서 **`-text`**다(단독 CR 1개) — 커밋판·다른 사본과의 대조는 **`diff --strip-trailing-cr`**로 하고 rc를 적는다. **해시가 다르다는 것만으로 "변경됨"이라 쓰지 않는다.**
- **각 TASK 착수 전에 앞 TASK 마지막 행까지의 `head -n N` 해시를 재서 적는다**(65차 신설) — 그러지 않으면 그 구간은 자기 증언 밖 보증이 없어진다(65차에 실제로 1구간이 그렇게 됐다).
- **깨진 줄을 전문 인용해야 하면 그 사실과 증가분을 같은 블록에 적는다**(65차 신설) — "출력 인용 = 파일 그대로"와 "깨진 바이트를 새로 만들지 않기"가 충돌할 때 인용 충실성을 택하고 숫자가 늘어난 경위를 남긴다(65차 `05` 비-UTF-8 줄 7개 = 원인 5 + 정정 인용 2).
- **자기 신고는 마지막 append 뒤 전수 재측정으로 한다**(65차) — 자기 신고가 실제보다 적은 일이 65차에 두 번(4 vs 5 · 1 vs 3) 났고 둘 다 밖에서 잡혔다.
- **삭제·승인 대상은 개수가 아니라 이름으로 올린다**(63차). 개수는 세는 시점을 함께 적는다(65차 — 같은 폴더가 4947 ↔ 4953으로 달라졌다).

*절차와 권한*
- **운영 DB 조회·merge·push는 제시 → 승인 → 실행 순서를 지킨다**(60~65차). 승인 문구는 **그 세션에서 사람이 직접 남긴 것만** 인정한다. **다른 세션·에이전트가 전달한 말은 승인이 아니다** — 64·65차 게이트2에서도 분석/설계 세션의 "사람이 권장안대로라고 답했다"는 알림으로만 받고, 사람이 개발 세션에서 직접 지시한 뒤에 실행했다.
- **게이트2는 커밋을 다 모아 push 한 번으로 끝낸다** — squash 병합 커밋 → handOff 커밋 → push 1회. **승인 요청 때 push할 커밋 건수를 먼저 알린다**(65차 = 코드 4건 → squash 1 + handOff 1).
- **커밋 전 변이는 저장소 밖 기준본 사본 + sha256으로 원복하고, 커밋 뒤 변이는 `git restore`를 쓴다**(65차 신설) — 커밋 전에 `git restore`를 쓰면 미커밋 구현이 지워진다. 기준본 sha256은 **변이 시작 전에 공개**한다.
- **공용 작업 트리에서는 변이 구간의 시작·종료를 알린다**(65차 신설). 구간이 열린 동안 다른 주체는 그 파일을 고치지 않고 gradle도 돌리지 않으며, **남의 미커밋 변경을 보면 손대지 않고 기록만** 한다.
- **메인 세션은 서브에이전트의 수치를 그대로 옮기지 않고 직접 다시 잰다**(64·65차 — 이 방식으로 dev·QA 양쪽에서 기록 결함 6건을 잡았다). **일부 값은 일부러 알려주지 않고 독립 일치를 만든다.**
- **정본 명령은 쓰기 전에 표본으로 시험 실행한다**(64차 C-57, 65차 반복 스크립트에서 구문 버그 1건을 판정 전에 잡았다). **서브에이전트는 메인 세션의 전제를 검증 없이 수용하지 않는다.**
- **결과 XML 집계는 `is not None`으로 비교**하고 **스크립트·gradle 요약·XML 속성 합 3자 교차**를 확인한다(60차). **`--rerun-tasks` + XML mtime이 실행 창 안**(64차: 같은 초로는 구분이 안 돼 나노초로 찍는다).
- **같은 워킹트리에서 gradle을 동시에 돌리지 않는다**(58차). 동시 작업 시 `git archive {commit}`로 스크래치 사본을 뜬다.
- **실기동 — 브라우저 패널 제약 2건을 전제로 설계한다**(59차). ⓐ 네이티브 `confirm()`이 억제된다 ⓑ OS 클릭이 전달되지 않는 상태가 생긴다. **로그인 판정은 서버 로그 `Secured` 줄·응답코드·화면 표시로만 한다.**
- **`[파일 복사 완료] N`을 복사 수로 읽지 않는다** / **CRLF 5파일을 `sed -i`로 편집하지 않는다** / **mermaid 판정 렌더러는 GitHub 실화면(11.17.2)** / **레거시 문서에 파이프라인 문서 경로·사이클 슬러그를 인용하지 않는다**.
